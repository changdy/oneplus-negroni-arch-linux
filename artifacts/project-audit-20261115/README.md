# 跨对话成果核对

见[整理规范与交付范围](../../docs/project-records.md)。[conversations.json](conversations.json) 保留逐个对话的来源、标题、归档状态、处理结果和主要文档，便于以后检查遗漏。数量固定于本次审阅时刻，不包含当前整理对话和后来新建的对话。

证据使用顺序是具体提交/代码与实测记录，再核对聊天的结论。对话中曾把 DMIC 路由误归为失败实验、把 USB2 LPM 假设当根因、把无硬件的红外模块当移植机会；相应主题采用较晚证据纠正，同时留下错误方向和否证过程。

清单和整理资料不包含原始聊天、密码、音视频、设备校准或分区备份。临时读取、构建及检查输出保留在本地 `logs/`，不随 Git 分发。
