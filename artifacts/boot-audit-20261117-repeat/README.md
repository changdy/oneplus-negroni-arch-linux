## 影响及验证范围

- **电量与蜂窝。** USB 电源在线。第 45 秒电池报告 0%、Discharging，约第 184 秒仍为 0%、Charging，电压 3.878 V。实际剩余电量未测。自动休眠前蜂窝已注册，唤醒后 `mmcli -L` 一直为空。此时基带 remoteproc 在运行，QRTR 可见 NAS、UIM、WDS。ModemManager 重启计数为 0，用户空间重新枚举失败的原因待查。未拨号或测试移动数据。
- **传感器。** 加速度、光线、距离的桌面属性均为 true，实际样本包括加速度 Z = 9.77 m/s²、光线 93–95 lux 和距离 FAR。角速度 D-Bus 返回三轴数据，两次检查之间样本文件也有更新。陀螺仪和桌面代理重启计数均为 0，没有本次陀螺仪启动失败或段错误记录。固件提供的安装矩阵全零，服务回退到单位矩阵，本次未转动手机验证轴向。SDSP 文件服务另有大量打开注册表文件写入的请求记录，第三次启动后持续运行。本次休眠发生在传感器就绪之前。此前一次普通重启的结果见[首次验证记录](../sensor-recovery-20261117/README.md#imu-修复与重启复测)。
- **图形与蓝牙。** GPU 固件 `a730_sqe.fw` 第 1.23 秒加载失败，第 12.42 秒从另一位置加载成功。Adreno 已绑定并有渲染节点。1440 宽度与 540 像素的 DSC 切片不匹配，DRM 仅列出 1080×2412。蓝牙先报告找不到带 `wcn` 前缀的固件，换用备用名称后初始化完成，控制器已上电。未测 GPU 负载或蓝牙连接。
- **音频、相机与闪光灯。** 音频记录 APM 命令超时、SoundWire 输入端口数量不匹配、MultiMedia4 Capture 缺后端及阻抗检测错误，ALSA 仍列出 OnePlus 声卡。相机枚举时 S5KJN1 未提供有效选区，libcamera 无可用的 dma-buf 分配器，关闭了软件去马赛克。处理 `white:flash` 的 udev 规则缺少 `fbd-ledctrl`。本次未做录放音、拍摄或灯光测试。
- **其他启动告警。** 引导程序传入的内核镜像未对齐，SMEM 报未知 DRAM 信息结构。触控所在 I²C 控制器出现一次 DMA 传输错误，随后已枚举触控输入节点。PMIC GLINK 创建 USB 设备依赖时报错，睡眠过程中 USB HS-PHY 与 PCIe 的 L2 状态均有告警，随后 PCIe 以 Gen3 ×1 建链，USB SSH 可用。充电驱动在开机第 12.8–14.5 秒集中输出 42 条 Type-C 状态工作日志。还观察到早期 QRTR 通告失败、PowerDevil 的 I²C 权限告警、NetworkManager 可选 NAT 模块缺失。RTC 把时间设为 1970 年，检查时 NTP 尚未同步。

本轮仅重启和采样，没有手动拉起服务、刷写分区或调整系统配置。检查覆盖到开机约 265 秒，日志未见内核 panic、Oops 或进程 core dump。
